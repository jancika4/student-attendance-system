# Student Attendance Management System

A web-based Student Attendance Management System developed using Flask, Python, MySQL, HTML and CSS.

## Features

- Student Dashboard
- Add Student
- Student Management
- Mark Attendance
- View Attendance
- Attendance Report
- MySQL Database Integration

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS

## How to Run

1. Install Python and MySQL.
2. Install required Python packages.
3. Configure the MySQL database.
4. Run the Flask application.

```bash
python app.py
